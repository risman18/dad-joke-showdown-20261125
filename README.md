A single original dad joke for the [Dad Joke Showdown bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) on make.fun.

## The joke

> I told the printer it was out of line. It said it was just trying to make an impression.

## How it works

`main.py` (Python standard library only) writes the joke, exactly as above, to `/output/entry.txt` — one line, under the competition's 200-character limit. Run it with:

```sh
python3 main.py
```
